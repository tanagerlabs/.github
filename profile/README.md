# Tanager Labs

Tanager Labs builds open research and engineering tools for understanding how
AI systems represent language, use compute, and translate technical behavior
into real-world cost.

TokEval is our open-source program for measuring, explaining, visualizing, and
improving multilingual LLM tokenization efficiency. Korean is the first
optimization case, while the work is designed for reproducible comparison
across languages, models, and serving systems.

| Project | Purpose |
| --- | --- |
| [TokEval](https://github.com/tanagerlabs/tokeval) | Reusable Python library for multilingual tokenizer evaluation. |
| [TokEval Explorer](https://github.com/tanagerlabs/tokeval-dashboard) | Public byte-safe token comparison dashboard and hosted-count Worker. |
| [TokEval Research](https://github.com/tanagerlabs/tokeval-research) | Research scope, experiment configurations, reproducible results, and writeups. |

Explore the live tokenizer comparison at [tokeval.dev](https://tokeval.dev).

Model weights and model cards will be published through a future Tanager Labs
organization on the Hugging Face Hub.
