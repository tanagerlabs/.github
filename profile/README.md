# Tanager Labs

Tanager Labs builds open research and engineering tools for understanding how
AI systems represent language, use compute, and translate technical behavior
into real-world cost.

TokEvals is our open-source program for measuring, explaining, visualizing, and
improving multilingual LLM tokenization efficiency. Korean is the first
optimization case, while the work is designed for reproducible comparison
across languages, models, and serving systems.

| Project | Purpose |
| --- | --- |
| [TokEvals](https://github.com/tokevals/tokevals) | Reusable Python library for multilingual tokenizer evaluation. |
| [TokEvals Explorer](https://github.com/tokevals/tokevals-explorer) | Public byte-safe token comparison dashboard and hosted-count Worker. |
| [TokEvals Research](https://github.com/tokevals/tokevals-research) | Research scope, experiment configurations, reproducible results, and writeups. |

Explore the live tokenizer comparison at [tokeval.dev](https://tokeval.dev).

Model weights and model cards will be published through the
[TokEvals organization on the Hugging Face Hub](https://huggingface.co/tokevals).
